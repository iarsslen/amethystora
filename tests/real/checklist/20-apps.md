# Amethystora apps

Every app below is the one program built from `apps/` (`/usr/lib/amethystora-<app>/amethystora-<app>`). The checks in "Every app" apply to each of them: run them once per app (Manual, Security, Updates, Notes, Logs, Backups, Control, Phone, Shelf) and note which app fails.
