# CONTRIBUTING

Thanks for helping out!

This repository builds the Amethystora images. Open an issue or pull request on [iarsslen/amethystora](https://github.com/iarsslen/amethystora).

Amethystora is based on [Bluefin](https://github.com/ublue-os/bluefin). The desktop layer it took from Bluefin's [projectbluefin/common](https://github.com/projectbluefin/common) now lives in this repository, under `system_files/shared`, so changes to it are made here.

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
