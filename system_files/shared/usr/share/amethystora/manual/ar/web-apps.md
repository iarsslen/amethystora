# تطبيقات الويب

كثير من التطبيقات التي تستخدمها مواقع ويب: البريد، والمحادثة، والموسيقى، والتقويم. يضع تطبيق الويب
موقعًا منها في نافذة خاصة به، بلا ألسنة ولا شريط عناوين، وله أيقونته الخاصة في شبكة التطبيقات والمرسى،
ومكانه الخاص في `Alt+Tab`.

## ثبّت واحدًا

من قائمة Amethystora (`Super+Alt+Space`)، اختر **Web apps** ثم **Install a web app**، وأجب عن ثلاثة
أسئلة: اسم، والعنوان، وأيقونة. اترك الأيقونة فارغة فتُجلب أيقونة الموقع نفسه. والأمر نفسه من الطرفية:

```bash
amethystora-webapp install "Proton Mail" mail.proton.me
amethystora-webapp install "Calendar" https://calendar.proton.me ~/Pictures/calendar.png
```

يمكن أن تكون الأيقونة صورة على الويب، أو ملفًا، أو اسم أيقونة من سمة الأيقونات.

## افتحه، ثبّته، أزله

تطبيق الويب موجود في شبكة التطبيقات مثل أي تطبيق آخر: ابحث عنه بـ`Super+Space`، وانقره بالزر الأيمن في
المرسى لتثبيته فيه. ولإزالة واحد، اختر **Remove a web app** من القائمة نفسها، أو:

```bash
amethystora-webapp remove "Proton Mail"
```

لفتح موقع كتطبيق ويب مرة واحدة دون تثبيته: `amethystora-webapp <address>`.

## أي متصفح يشغّلها

تُفتح تطبيقات الويب في متصفحك المبدئي، وهو Firefox ما لم تختر غيره، وتتبعك حين تغيّره. ولا يمكن أن
يصير تطبيقَ ويب إلا عنوان من نوع `http` أو `https`.

| المتصفح المبدئي | كيف يُفتح تطبيق الويب |
| --- | --- |
| Brave أو Chrome أو Chromium أو Edge أو Vivaldi أو Opera | في نافذة التطبيقات الخاصة بالمتصفح نفسه. ويتشارك مع المتصفح عمليات الولوج وكلمات السر والامتدادات. |
| Firefox أو LibreWolf أو Zen أو Floorp أو Waterfox | في نافذة بلا ألسنة ولا شريط أدوات، بملف تعريف خاص به. ليس لـFirefox نافذة تطبيقات، لذا يحتفظ كل تطبيق ويب بعمليات ولوجه الخاصة ولا يرى ما في المتصفح. |
| أي متصفح آخر | في متصفح من السطرين أعلاه: متصفح مبني على Chromium إن كنت ثبّتّ واحدًا، وإلا فـFirefox. |

ملف تعريف تطبيق الويب في Firefox موجود في `~/.local/share/amethystora-webapp`، أو في مجلد المتصفح تحت
`~/.var/app` حين يكون المتصفح من Flatpak. وإزالة تطبيق الويب تحذفه، بما فيه من عمليات ولوج.
