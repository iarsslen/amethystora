# التنقّل في سطح المكتب

سطح المكتب هو GNOME، مرتَّبًا ليُستخدم من لوحة المفاتيح. كل ما هنا يعمل بالفأرة أيضًا، لكن ما إن تعتاد
أصابعك المفاتيح حتى يندر أن تمدّ يدك إليها.

## الشريط العلوي

- **على اليمين**، مساحات العمل الست. المساحة التي أنت فيها مميَّزة؛ انقر غيرها للانتقال إليها.
- **في الوسط**، الساعة. انقرها، أو اضغط `Super+V`، لعرض الإخطارات والتقويم.
- **على اليسار**، مقاييس المعالج والذاكرة والشبكة، ثم قائمة النظام: الشبكة اللاسلكية والصوت والطاقة
  وبقية الإعدادات السريعة.

تتبع المقاييس ومساحات العمل ألوان [السمة](themes.md) الحالية. ويستطيع الشريط أيضًا عرض
[أدوات مصغّرة](widgets.md) خاصة بك يصنعها لك وكيل الذكاء الاصطناعي.

## العثور على الأشياء

- يبحث `Super+Space` عن التطبيقات والملفات والإعدادات، ويشغّل ما تختاره.
- يفتح `Super` وحده النظرة العامة: كل النوافذ المفتوحة دفعة واحدة، مع البحث في الأعلى.
- يعرض `Super+A` كل التطبيقات المثبّتة.

يتسامح البحثان مع الأخطاء الإملائية في أسماء التطبيقات: فـ`calxu` يجد الحاسبة (Calculator) مع ذلك.

## الحافظة

يفتح `Super+Shift+V` سجل الحافظة: آخر 15 شيئًا نسختها. اختر أحدها لتنسخه من جديد، واكتب للبحث، وثبّت
ما تعود إليه باستمرار. وهو أيضًا أيقونة الحافظة في الشريط العلوي.

لا يبقى السجل إلا ما دامت جلستك، ولا يُحفظ منه إلا ما ثبّتّه. قبل نسخ شيء سري، فعّل **Private mode**
(الوضع الخاص) في القائمة نفسها، فلا يُسجَّل شيء حتى تعطّله.

## المرسى

يضم المرسى في الأسفل التطبيقات المثبّتة فيه وتلك التي تعمل. ينقلك `Alt+1` إلى `Alt+9` إلى التطبيق في
تلك الخانة، ويفتحه إن لم يكن يعمل. انقر تطبيقًا بالزر الأيمن لتثبيته في المرسى أو إزالته منه.

## قائمة Amethystora

يفتح `Super+Alt+Space` قائمة واحدة للأمور الموزّعة لولاها بين الإعدادات والطرفية
و[`ame`](terminal.md#ame). مُدخلاتها بالإنجليزية:

| المُدخل | ما يفعله |
| --- | --- |
| Ask an agent | يفتح [وكيل الذكاء الاصطناعي](ai-agent.md) |
| Diagnose a problem | يجعل الوكيل يكتشف سبب تعطّل شيء ما |
| Make a widget | يجعل الوكيل يصنع [أداة مصغّرة](widgets.md) للشريط العلوي |
| Theme | منتقي السمات |
| Background | خلفيات السمة الحالية |
| Keybindings | مفاتيح الاختصار، في الطرفية |
| Manual | هذا الدليل |
| Web apps | تثبيت [تطبيق ويب](web-apps.md) أو إزالته |
| Apps and system commands | كل أوامر `ame`، كلٌّ في مجموعته |
| System | القفل، وتسجيل الخروج، وإعادة التشغيل، والإطفاء، والتحقق من التحديثات، وتقرير الأمان |

تنقّل بمفاتيح الأسهم أو اكتب للتصفية، و`Enter` للاختيار، و`Esc` للرجوع.

## ترتيب النوافذ متجاورةً

يرتّب PaperWM النوافذ نيابةً عنك. كل مساحة عمل شريطٌ من النوافذ المتجاورة بكامل ارتفاعها، وقد يكون
الشريط أعرض من الشاشة. تُفتح النافذة الجديدة على يمين النافذة التي أنت فيها، ولا تتراكب النوافذ أبدًا،
ويتمرّر الشريط ليُبقي النافذة المركَّز عليها ظاهرة:

```
  ┌────────┬──────────────┬──────────────────────┬────────┐
  │  Mail  │   Terminal   │       Browser        │  Chat  │
  └────────┴──────────────┴──────────────────────┴────────┘
           ╰──────────── the screen ─────────────╯
```

ما زال Mail وChat مفتوحين، خارج الحافة فقط. يمرّر `Super+Left` الشريط عائدًا إلى Mail. ادفع المؤشر نحو
الحافة اليسرى أو اليمنى للشاشة لترى ما وراءها، وانقر نافذة هناك للانتقال إليها. وعلى لوحة اللمس، اسحب
بثلاثة أصابع لتحريك الشريط.

تتبع المفاتيح نمطًا واحدًا: `Super` مع سهم ينقلك إلى نافذة أخرى. أضف `Ctrl` فتتحرك النافذة بدلًا من
ذلك. أضف `Shift` فتنتقل إلى شاشة أخرى.

### التنقّل

| المفتاح | ما يفعله |
| --- | --- |
| `Super+Left` / `Super+Right` | النافذة إلى اليسار / اليمين |
| `Super+Up` / `Super+Down` | النافذة أعلاها / أسفلها، حين تتشارك النوافذ عمودًا |
| `Super+Home` / `Super+End` | النافذة الأولى / الأخيرة في مساحة العمل |
| `Super+[` / `Super+]` | حرّك الشريط دون تغيير النافذة المركَّز عليها |
| `Super+Shift` مع سهم | الشاشة في ذلك الاتجاه |

### الترتيب

| المفتاح | ما يفعله |
| --- | --- |
| `Super+Ctrl+Left` / `Super+Ctrl+Right` | انقل النافذة يسارًا / يمينًا على طول الشريط |
| `Super+Ctrl+Up` / `Super+Ctrl+Down` | انقلها إلى الأعلى / الأسفل في عمودها |
| `Super+I` | اسحب النافذة التي على اليمين إلى هذا العمود، أسفل هذه النافذة |
| `Super+O` | ادفع النافذة السفلى من هذا العمود إلى عمود خاص بها |
| `Super+Shift+O` | ادفع هذه النافذة إلى عمود خاص بها |
| `Super+Ctrl+Page Up` / `Page Down` | انقلها إلى مساحة العمل السابقة / التالية |
| `Super+Shift+Ctrl` مع سهم | انقلها إلى الشاشة في ذلك الاتجاه |
| `Super+T`، مع إبقاء `Super` مضغوطًا | احمل النافذة معك أثناء تنقّلك، وأفلتها حيث ترفع إصبعك |

### تغيير الحجم

| المفتاح | ما يفعله |
| --- | --- |
| `Super+R` | تنقّل بالعرض بين 38% و50% و62% من الشاشة (ويعود `Super+Alt+R` خطوة إلى الوراء) |
| `Super+Shift+R` | الأمر نفسه لارتفاع نافذة في عمود |
| `Super+F` | املأ عرض الشاشة، ثم عُد |
| `Super+C` | وسّط النافذة على الشاشة |
| `Super+Shift+C` | الموضع الذي يمرّر إليه الشريط النافذة المركَّز عليها: حيث تظهر بالكاد، أو الوسط، أو الحافة |
| `Super+Shift+W` | أين تُفتح النوافذ الجديدة: على اليمين، أو على اليسار، أو أسفل هذه النافذة |

### النوافذ العائمة

تطفو مربعات الحوار فوق الشريط من تلقاء نفسها. يرفع `Super+Ctrl+Escape` النافذة المركَّز عليها من الشريط
لتطفو هي أيضًا، ويعيدها إليه. ويُخفي `Super+Alt+Escape` كل النوافذ المعوَّمة بهذه الطريقة دفعة واحدة،
ثم يعيد إظهارها.

### وما تبقّى

| المفتاح | ما يفعله |
| --- | --- |
| `Super+N` | نافذة جديدة من التطبيق الذي أنت فيه |
| `Super+Ctrl+B` | أخفِ الشريط العلوي في مساحة العمل هذه أو أظهره |

إعدادات PaperWM موجودة تحت **PaperWM** في **مدير الامتدادات**. وتشمل الفراغات بين النوافذ، والعروض التي
يتنقّل بينها `Super+R`، وكل المفاتيح، ومنها ما لا تذكره هذه الصفحة.

### النوافذ الكلاسيكية

إن كنت تفضّل نوافذ عائمة ومتراكبة، كما في Windows وmacOS، فانتقل إلى التخطيط الكلاسيكي:

```bash
ame desktop layout classic
```

يعطّل ذلك PaperWM، وتُبقيه التحديثات معطّلًا. تُفتح النوافذ حينها حيث يضعها GNOME، وتسحبها من شريط
العنوان. يكبّر `Super+Up` النافذة ويعيد `Super+Down` حجمها، ويضع `Super+Left` / `Super+Right` النافذة
في ذلك النصف من الشاشة، وينقلها `Super+Shift+Left` / `Super+Shift+Right` إلى الشاشة التالية. ويعيد
`ame desktop layout tiling` الشريط. وعند ولوجك أول مرة، يعرض عليك إخطار الخيار نفسه.

## النوافذ

| المفتاح | ما يفعله |
| --- | --- |
| `Super+W` | أغلق النافذة |
| `Super+Backspace` | غيّر الحجم بمفاتيح الأسهم |
| `Shift+F11` | ملء الشاشة، مع إبقاء شريط العنوان |
| `Super+Tab` / `Alt+Tab` | بدّل بين التطبيقات / بين النوافذ |

تصغّر الأزرار التي على يسار كل شريط عنوان النافذة وتكبّرها وتغلقها.

## مساحات العمل

هي ست دائمًا، لذا يعني `Super+3` المكان نفسه دائمًا. من الطرق الشائعة لاستخدامها: المتصفح على 1،
والطرفية على 2، والمحادثة على 6. ينقل `Super+Shift+3` النافذة المركَّز عليها إلى مساحة العمل 3. وينقلك
`Super+Page Up` / `Super+Page Down` إلى مساحة العمل السابقة / التالية، وينقل
`Super+Shift+Ctrl+Left` / `Super+Shift+Ctrl+Right` النافذة إلى الشاشة التالية.

## الامتدادات

تأتي امتدادات GNOME Shell هذه مع الصورة:

| الامتداد | ما يفعله |
| --- | --- |
| PaperWM | [ترتيب النوافذ متجاورةً](#tiling-windows): نوافذ متجاورة على شريط متمرّر |
| Space Bar | مساحات العمل في الشريط العلوي |
| TopHat | مقاييس المعالج والذاكرة والشبكة |
| Dash to Dock | المرسى |
| Search Light | البحث على `Super+Space` |
| Fuzzy App Search | بحث عن التطبيقات يتسامح مع الأخطاء الإملائية |
| Clipboard Indicator | [سجل الحافظة](#the-clipboard) على `Super+Shift+V` |
| Blur my Shell | الزجاج المصنفر خلف اللوحة والنظرة العامة والنوافذ |
| Just Perfection | حركات أسرع، ودون نافذة منبثقة عند تغيير مساحة العمل |
| AppIndicator | أيقونات علبة النظام للتطبيقات التي تستخدمها |
| Caffeine | مفتاح في الإعدادات السريعة يُبقي الشاشة مستيقظة |
| GSConnect | هاتفك العامل بنظام Android: الإخطارات والملفات والحافظة والرسائل النصية |
| Logo Menu | شعار Amethystora في أعلى اليمين: اختصارات إلى أدوات النظام |
| Gradia | دوّن على لقطة الشاشة فور التقاطها |
| Bazaar integration | يربط GNOME Shell بـBazaar، مركز البرمجيات |

عطّل أيًّا منها، أو غيّر إعداداته، من **مدير الامتدادات**. أمر واحد ينبغي معرفته: بعد كل تحديث للصورة
تُفعَّل امتدادات الصورة من جديد، كي لا يبقى امتداد عُطّل بالخطأ، أو بسبب انهيار، معطّلًا إلى الأبد.
فتعطيل أحدها يدوم حتى التحديث التالي. والاستثناء هو PaperWM في [التخطيط الكلاسيكي](#classic-windows)، إذ
يبقى معطّلًا.

## الملفات

يفتح `Super+Shift+F` نافذة للملفات، ويفتح `Super+E` مجلد المنزل. تُفتح المجلدات في عرض شبكي، تظهر فيه
مجلدات سمة الأيقونات برسومها كما هي.
