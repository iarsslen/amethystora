# مفاتيح الاختصار

صُمّم Amethystora ليُقاد من لوحة المفاتيح. `Super` هو المفتاح الذي يحمل شعار Windows أو Command. وهذه
القائمة هي أيضًا ما يعرضه `ame desktop keybindings`، وتصل قائمة Amethystora (`Super+Alt+Space`) إلى
معظم ما تفعله هذه المفاتيح.

## ترتيب النوافذ

يضع PaperWM نوافذ مساحة العمل متجاورةً على شريط يتمرّر ليُبقي النافذة المركَّز عليها ظاهرة. `Super` مع
سهم ينقلك بين النوافذ، وإضافة `Ctrl` تنقل النافذة نفسها، وإضافة `Shift` تنقلك إلى شاشة أخرى.

| المفتاح | الإجراء |
| --- | --- |
| `Super+Left` / `Right` / `Up` / `Down` | ركّز على النافذة في ذلك الاتجاه |
| `Super+Ctrl+Left` / `Right` / `Up` / `Down` | انقل النافذة في ذلك الاتجاه |
| `Super+Home` / `Super+End` | النافذة الأولى / الأخيرة في مساحة العمل |
| `Super+[` / `Super+]` | حرّك الشريط دون تغيير التركيز |
| `Super+R` / `Super+Alt+R` | تنقّل بالعرض بين 38% و50% و62% من الشاشة / إلى الوراء |
| `Super+Shift+R` | تنقّل بارتفاع نافذة في عمود |
| `Super+F` | املأ عرض الشاشة، ثم عُد |
| `Super+C` | وسّط النافذة |
| `Super+I` | اسحب النافذة التي على اليمين إلى هذا العمود |
| `Super+O` / `Super+Shift+O` | ادفع النافذة السفلى / هذه النافذة إلى عمود خاص بها |
| `Super+T` | احمل النافذة معك ما دام `Super` مضغوطًا، وأفلتها حيث ترفع إصبعك |
| `Super+Ctrl+Escape` | عوّم النافذة فوق الشريط، أو أعدها إليه |
| `Super+Alt+Escape` | أخفِ النوافذ العائمة أو أظهرها |
| `Super+Shift+C` | الموضع الذي يمرّر إليه الشريط النافذة المركَّز عليها: حيث تظهر، الوسط، الحافة |
| `Super+Shift+W` | أين تُفتح النوافذ الجديدة: يمينًا، يسارًا، أسفل |
| `Super+N` | نافذة جديدة من التطبيق الذي أنت فيه |
| `Super+Ctrl+B` | أخفِ الشريط العلوي في مساحة العمل هذه أو أظهره |
| `Super+Backspace` | غيّر حجم النافذة بمفاتيح الأسهم |
| `Super+W` | أغلق النافذة |
| `Shift+F11` | ملء الشاشة، مع إبقاء شريط العنوان |

## مساحات العمل

ست مساحات عمل ثابتة، فيعني الرقم المساحة نفسها دائمًا. المساحة التي أنت فيها مميَّزة في الشريط العلوي على
اليمين.

| المفتاح | الإجراء |
| --- | --- |
| `Super+1` … `Super+6` | انتقل إلى مساحة العمل تلك |
| `Super+Shift+1` … `Super+Shift+6` | انقل النافذة إليها |
| `Super+Page Up` / `Page Down` | مساحة العمل السابقة / التالية |
| `Super+Ctrl+Page Up` / `Page Down` | انقل النافذة إلى مساحة العمل السابقة / التالية |
| `Super+Shift+Left` / `Right` / `Up` / `Down` | ركّز على الشاشة في ذلك الاتجاه |
| `Super+Shift+Ctrl+Left` / `Right` / `Up` / `Down` | انقل النافذة إلى تلك الشاشة |
| `Alt+1` … `Alt+9` | انتقل إلى التطبيق المثبّت في تلك الخانة من المرسى |
| `Super+Tab` / `Alt+Tab` | بدّل التطبيق / النافذة |

## التشغيل

| المفتاح | الإجراء |
| --- | --- |
| `Super+Space` | ابحث وشغّل |
| `Super` | النظرة العامة: كل النوافذ المفتوحة، والبحث |
| `Super+A` | كل التطبيقات المثبّتة |
| `Super+Return` | الطرفية |
| `Ctrl+Alt+T` | الطرفية، كما تفتحها معظم أسطح مكتب Linux |
| `Super+Shift+B` | المتصفح |
| `Super+Shift+F` | الملفات |
| `Super+E` | مجلد المنزل |
| `Ctrl+Shift+Esc` | التطبيق Mission Center، لرؤية ما يعمل وإيقافه |
| `Ctrl+Alt+Space` أو `Super+.` | منتقي الرموز التعبيرية |
| `Super+Ctrl+Shift+A` | وكيل ذكاء اصطناعي يعرف هذا النظام (يعطّله `ame agent toggle`) |
| `Super+F1` | هذا الدليل |

## المظهر

| المفتاح | الإجراء |
| --- | --- |
| `Super+Alt+Space` | قائمة Amethystora |
| `Super+Ctrl+Shift+Space` | اختر سمة |
| `Super+Ctrl+Space` | الخلفية التالية لهذه السمة |
| `Super+Ctrl+D` | بدّل بين السمة الفاتحة والداكنة |

والأمر نفسه من الطرفية: `amethystora-theme list`، و`amethystora-theme set <name>`،
و`amethystora-theme bg next`، أو `ame desktop theme`.

## سطح المكتب

| المفتاح | الإجراء |
| --- | --- |
| `Super+V` | الإخطارات والتقويم |
| `Super+Shift+V` | سجل الحافظة |
| `Super+L` | اقفل الشاشة |
| `Super+D` | أظهر سطح المكتب |
| `Print` | التقط لقطة شاشة أو سجّل الشاشة |
| `Ctrl+Shift+Alt+R` | ابدأ تسجيل الشاشة أو أوقفه |
| `Super+Shift+Space` | تخطيط لوحة المفاتيح التالي، حين يكون لديك أكثر من واحد |
