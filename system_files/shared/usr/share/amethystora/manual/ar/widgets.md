# الأدوات المصغّرة

يستطيع الشريط العلوي أن يعرض أشياء خاصة بك: مؤقت تركيز، والطقس، والبريد غير المقروء، وما إذا كانت VPN
متصلة، وعدد طلبات الدمج التي تنتظر مراجعتك. كل واحد منها *أداة مصغّرة*، أي برنامج صغير يحوّل الشريط
مخرجاته إلى تسمية وأيقونة وقائمة. ولست مضطرًا إلى كتابته بنفسك: فـ[وكيل الذكاء الاصطناعي](ai-agent.md)
يكتبه.

## اطلب واحدة من الوكيل

اختر **Make a widget** (اصنع أداة مصغّرة) في قائمة Amethystora (`Super+Alt+Space`) وقل ما ينبغي أن تعرضه،
أو نفّذ:

```bash
amethystora-widgets make "a pomodoro timer"
amethystora-widgets make "how many pull requests wait for my review on GitHub"
amethystora-widgets make                          # the agent asks you what you want
```

يكتب الوكيل الأداة المصغّرة ويفحصها، فتظهر في الشريط فور حفظها، دون حاجة إلى تسجيل الخروج. واطلب
التعديلات بالطريقة نفسها: «اجعل أداة الطقس تعرض الغد أيضًا».

حين تتوقف أداة مصغّرة عن العمل، يعرض الشريط علامة تحذير مكانها. انقرها لتقرأ ما ساء؛ ويسلّم
**Fix it with the AI agent** (أصلحها بوكيل الذكاء الاصطناعي) المشكلةَ إلى الوكيل.

## الأوامر

| الأمر | ما يفعله |
| --- | --- |
| `amethystora-widgets` | يسرد أدواتك المصغّرة، وأيها مفعّل |
| `amethystora-widgets make ["<idea>"]` | يجعل الوكيل يصنع واحدة |
| `amethystora-widgets new <name> [<example>]` | يبدأ واحدة من مثال: `hello` أو `pomodoro` أو `do-not-disturb` |
| `amethystora-widgets run <name>` | يشغّلها مرة واحدة كما يفعل الشريط، ويبيّن ما فيها من خلل |
| `amethystora-widgets fix <name> ["<what is wrong>"]` | يجعل الوكيل يكتشف سبب فشلها ويصلحها |
| `amethystora-widgets off <name>` و`on <name>` | يخفيها من الشريط، أو يعيد إظهارها |
| `amethystora-widgets remove <name>` | ينقلها إلى المهملات |
| `amethystora-widgets restart` | يوقف كل الأدوات المصغّرة ويشغّلها من جديد |

ويشغّل `ame desktop widgets` الأوامر نفسها.

## اصنع واحدة بنفسك

الأداة المصغّرة مجلد في `~/.config/amethystora/widgets`، فيه ملف `widget.json` يسمّي أمرًا ويحدد عدد مرات
تشغيله، والأمر نفسه، وهو في العادة نص برمجي قصير. يطبع النص البرمجي سطرًا ليعرضه الشريط: نصًّا عاديًا، أو
JSON فيه أيقونة، ولون من السمة، وقائمة تشغّل عناصرها أوامر أو تفتح روابط أو تقلب مفاتيح.

ينسخ `amethystora-widgets new mywidget` المثال `hello` إلى مكانه لتبدأ منه، ويفحصه
`amethystora-widgets run mywidget` بعد كل تغيير. والصيغة الكاملة موصوفة في دليل الوكيل نفسه،
`/usr/share/amethystora/agents/skills/amethystora-widgets/SKILL.md`؛ والأمثلة في
`/usr/share/amethystora/widgets/examples`.

## الأمان

تعمل الأداة المصغّرة باسمك، مع وصول إلى ملفاتك، مثل أي برنامج تشغّله. لا تحتفظ إلا بالأدوات المصغّرة التي
قرأتها أو طلبتها من الوكيل، واقرأ ما يقترحه الوكيل قبل أن توافق، فهو يسألك قبل أن يكتب أي شيء.

تعمل الأدوات المصغّرة خارج GNOME Shell، لذا فإن المعطوبة أو البطيئة منها تعرض علامة تحذير بدلًا من تجميد
سطح المكتب أو إنهاء جلستك. وتتوقف ما دامت الشاشة مقفلة.
