# وكيل الذكاء الاصطناعي

يفتح `Super+Ctrl+Shift+A` وكيل ذكاء اصطناعي في الطرفية: Claude Code مبدئيًا، أو Opencode إن كنت تفضّله.
ويأتي معه مهارةٌ تشرح له هذا النظام، فيعرف أي الملفات تخص الصورة وأيها لك أن تغيّرها، وكيف تعمل السمات
ومفاتيح الاختصار، وكيف تُثبَّت البرمجيات على نظام قائم على صورة، وما ينبغي أن يسألك عنه قبل أن يمسّ أي
شيء.

اسأله بلغة عادية:

- «اجعل أيقونات المرسى أصغر.»
- «لماذا تعمل مروحة حاسوبي المحمول دائمًا؟»
- «أنشئ مشروع Python باستخدام uv في ‎~/code/scraper.»
- «أضف مفتاح اختصار يفتح Mission Center.»
- «اصنع أداة مصغّرة للشريط العلوي تعرض الطقس.» انظر [الأدوات المصغّرة](widgets.md).

يبدأ في وضعه العادي، فيسألك قبل أن ينفّذ أمرًا أو يغيّر ملفًا. اقرأ ما يقترحه قبل أن توافق.

## تشخيص مشكلة

يسلّم المُدخل **Diagnose a problem** (تشخيص مشكلة) في قائمة Amethystora (`Super+Alt+Space`) الوكيلَ أمرًا
ساء: انهيارًا، أو خدمة فشلت، أو وصفك أنت («ينقطع الاتصال اللاسلكي بعد التعليق»). فيتقصّى الأمر من السجلات
وتقارير الانهيار، دون أن يغيّر شيئًا، ثم يعود بالسبب وإصلاح مقترح.

```bash
amethystora-agent diagnose                       # look for anything that failed recently
amethystora-agent diagnose "wifi drops after suspend"
amethystora-agent diagnose NetworkManager.service
amethystora-agent diagnose 4242                  # a process ID
```

وتسلّمه التطبيقات ما ساء حيث تراه يسوء: **اسأل الوكيل عن السبب** في **التحديثات** حين لا يكتمل تحديث،
و**اسأل الوكيل** في **الأمان** بجانب كل ما يحتاج إلى انتباهك، و**اسأل الوكيل** في **السجلات** بجانب انهيار
أو شيء كتبته خدمة. ولا تمرّر إلا اسم الخدمة، أو رقم العملية، أو كلمات التقرير نفسها، ثم يقرأ الوكيل
البقية بنفسه. وما دامت ميزات الوكيل معطّلة، فلا وجود لهذه الأزرار.

## الأوامر

| الأمر | ما يفعله |
| --- | --- |
| `amethystora-agent` | افتح الوكيل (مثل `Super+Ctrl+Shift+A`) |
| `amethystora-agent ask "<question>"` | افتحه مع سؤال أول |
| `amethystora-agent diagnose [...]` | اعرف سبب تعطّل شيء ما، دون تغيير أي شيء |
| `amethystora-agent use claude` أو `use opencode` | اختر الوكيل |
| `amethystora-agent install` | ثبّت الوكيل المختار مسبقًا؛ ويفعل ذلك أيضًا `ame agent install` |
| `ame agent toggle` | عطّل ميزات الوكيل، أو أعد تفعيلها |

## التثبيت والتحديث

ليس الوكلاء جزءًا من الصورة، لأنهم يصدرون إصدارات جديدة أكثر بكثير مما تفعل الصورة. في أول مرة تفتح
أحدهم، يعرض تثبيته في مجلد المنزل بمثبّت صانعه نفسه. ومن بعدها يحدّث نفسه حين تقرر أنت:
`claude update` أو `opencode upgrade`. ويُثبَّت Claude Code من قناته المستقرة، وهي إصدار عمره نحو أسبوع.
ولأنه يعيش في مجلد المنزل، فإن النسخة نفسها تعمل أيضًا داخل أي حاوية toolbox أو distrobox.

## الخصوصية والتعطيل

لا يفعل أي من الوكيلين شيئًا حتى تلج إليه، وما ترسله إليه يذهب إلى المزوّد الذي ولجت إليه. يزيل
`ame agent toggle` مُدخلات القائمة، ويعطّل مفتاح الاختصار، ويفك ربط المهارة؛ أما الوكيل الذي ثبّتّه فيبقى
مثبّتًا في كل الأحوال.
