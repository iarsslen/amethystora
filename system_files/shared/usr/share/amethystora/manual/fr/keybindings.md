# Raccourcis clavier

Amethystora est conçu pour se piloter au clavier. `Super` est la touche qui porte le logo Windows ou
Commande. Cette liste est aussi ce qu’affiche `ame desktop keybindings`, et le menu Amethystora
(`Super+Alt+Space`) donne accès à l’essentiel de ce que font ces touches.

## Mosaïque

PaperWM place les fenêtres d’un espace de travail côte à côte sur une bande qui défile pour garder la
fenêtre active visible. `Super` et une flèche passe d’une fenêtre à l’autre, avec `Ctrl` en plus c’est
la fenêtre elle-même qui se déplace, avec `Shift` en plus vous passez à un autre écran.

| Touche | Action |
| --- | --- |
| `Super+Left` / `Right` / `Up` / `Down` | Activer la fenêtre dans cette direction |
| `Super+Ctrl+Left` / `Right` / `Up` / `Down` | Déplacer la fenêtre dans cette direction |
| `Super+Home` / `Super+End` | La première / dernière fenêtre de l’espace de travail |
| `Super+[` / `Super+]` | Faire glisser la bande sans changer de fenêtre active |
| `Super+R` / `Super+Alt+R` | Faire passer la largeur par 38 %, 50 % et 62 % de l’écran / en arrière |
| `Super+Shift+R` | Faire varier la hauteur d’une fenêtre dans une colonne |
| `Super+F` | Occuper toute la largeur de l’écran, et revenir |
| `Super+C` | Centrer la fenêtre |
| `Super+I` | Faire entrer la fenêtre de droite dans cette colonne |
| `Super+O` / `Super+Shift+O` | Sortir la fenêtre du bas / cette fenêtre dans une colonne à part |
| `Super+T` | Emporter la fenêtre tant que `Super` est maintenu, et la déposer là où vous relâchez |
| `Super+Ctrl+Escape` | Faire flotter la fenêtre au-dessus de la bande, ou l’y remettre |
| `Super+Alt+Escape` | Masquer ou afficher les fenêtres flottantes |
| `Super+Shift+C` | Où la bande amène une fenêtre active : dans le champ, au centre, au bord |
| `Super+Shift+W` | Où s’ouvrent les nouvelles fenêtres : à droite, à gauche, en dessous |
| `Super+N` | Une nouvelle fenêtre de l’application en cours |
| `Super+Ctrl+B` | Masquer ou afficher la barre supérieure sur cet espace de travail |
| `Super+Backspace` | Redimensionner la fenêtre avec les flèches |
| `Super+W` | Fermer la fenêtre |
| `Shift+F11` | Plein écran, en gardant la barre de titre |

## Espaces de travail

Six espaces de travail fixes : un numéro désigne donc toujours le même. Celui sur lequel vous êtes est
mis en évidence à gauche de la barre supérieure.

| Touche | Action |
| --- | --- |
| `Super+1` … `Super+6` | Aller à cet espace de travail |
| `Super+Shift+1` … `Super+Shift+6` | Y emmener la fenêtre |
| `Super+Page Up` / `Page Down` | L’espace de travail précédent / suivant |
| `Super+Ctrl+Page Up` / `Page Down` | Emmener la fenêtre vers l’espace de travail précédent / suivant |
| `Super+Shift+Left` / `Right` / `Up` / `Down` | Activer l’écran dans cette direction |
| `Super+Shift+Ctrl+Left` / `Right` / `Up` / `Down` | Déplacer la fenêtre vers cet écran |
| `Alt+1` … `Alt+9` | Aller à l’application épinglée à cet emplacement du dock |
| `Super+Tab` / `Alt+Tab` | Changer d’application / de fenêtre |

## Lancer

| Touche | Action |
| --- | --- |
| `Super+Space` | Rechercher et lancer |
| `Super` | La vue d’ensemble : toutes les fenêtres ouvertes, et la recherche |
| `Super+A` | Toutes les applications installées |
| `Super+Return` | Terminal |
| `Ctrl+Alt+T` | Terminal, comme le lancent la plupart des bureaux Linux |
| `Super+Shift+B` | Navigateur |
| `Super+Shift+F` | Fichiers |
| `Super+E` | Dossier personnel |
| `Ctrl+Shift+Esc` | Mission Center, pour voir et arrêter ce qui tourne |
| `Ctrl+Alt+Space` ou `Super+.` | Sélecteur d’émojis |
| `Super+Ctrl+Shift+A` | Un agent IA qui connaît ce système (`ame agent toggle` le désactive) |
| `Super+F1` | Ce manuel |

## Apparence

| Touche | Action |
| --- | --- |
| `Super+Alt+Space` | Le menu Amethystora |
| `Super+Ctrl+Shift+Space` | Choisir un thème |
| `Super+Ctrl+Space` | Fond d’écran suivant pour ce thème |
| `Super+Ctrl+D` | Basculer entre les thèmes clair et sombre |

La même chose depuis un terminal : `amethystora-theme list`, `amethystora-theme set <name>`,
`amethystora-theme bg next`, ou `ame desktop theme`.

| `Super+Shift+V` | L’historique du presse-papiers |
| `Super+L` | Verrouiller l’écran |
