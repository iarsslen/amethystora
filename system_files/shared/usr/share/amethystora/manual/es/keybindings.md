# Atajos de teclado

Amethystora está pensado para manejarse con el teclado. `Super` es la tecla con el logotipo de Windows
o de Comando. Esta lista es también lo que muestra `ame desktop keybindings`, y el menú de Amethystora
(`Super+Alt+Space`) llega a casi todo lo que hacen estas teclas.

## Mosaico

PaperWM coloca las ventanas de un área de trabajo una al lado de otra en una tira que se desplaza para
mantener a la vista la que tiene el foco. `Super` y una flecha mueven entre ventanas; añadiendo `Ctrl`
se mueve la propia ventana, y añadiendo `Shift` se pasa a otro monitor.

| Tecla | Acción |
| --- | --- |
| `Super+Left` / `Right` / `Up` / `Down` | Dar el foco a la ventana en esa dirección |
| `Super+Ctrl+Left` / `Right` / `Up` / `Down` | Mover la ventana en esa dirección |
| `Super+Home` / `Super+End` | La primera / última ventana del área de trabajo |
| `Super+[` / `Super+]` | Desplazar la tira sin cambiar el foco |
| `Super+R` / `Super+Alt+R` | Cambiar el ancho entre el 38 %, el 50 % y el 62 % de la pantalla / hacia atrás |
| `Super+Shift+R` | Cambiar la altura de una ventana en una columna |
| `Super+F` | Ocupar todo el ancho de la pantalla, y volver |
| `Super+C` | Centrar la ventana |
| `Super+I` | Traer la ventana de la derecha a esta columna |
| `Super+O` / `Super+Shift+O` | Sacar la ventana de abajo / esta ventana a una columna propia |
| `Super+T` | Llevar la ventana consigo mientras mantiene pulsada `Super`, y dejarla donde suelte la tecla |
| `Super+Ctrl+Escape` | Hacer flotar la ventana sobre la tira, o devolverla a ella |
| `Super+Alt+Escape` | Ocultar o mostrar las ventanas flotantes |
| `Super+Shift+C` | Hasta dónde desplaza la tira una ventana con el foco: a la vista, al centro, al borde |
| `Super+Shift+W` | Dónde se abren las ventanas nuevas: a la derecha, a la izquierda, debajo |
| `Super+N` | Una ventana nueva de la aplicación que está usando |
| `Super+Ctrl+B` | Ocultar o mostrar la barra superior en esta área de trabajo |
| `Super+Backspace` | Cambiar el tamaño de la ventana con las flechas |
| `Super+W` | Cerrar la ventana |
| `Shift+F11` | Pantalla completa, conservando la barra de título |

## Áreas de trabajo

Seis áreas de trabajo fijas, así que un número siempre corresponde a la misma. La que está usando
aparece resaltada a la izquierda de la barra superior.

| Tecla | Acción |
| --- | --- |
| `Super+1` … `Super+6` | Ir a esa área de trabajo |
| `Super+Shift+1` … `Super+Shift+6` | Llevar la ventana allí |
| `Super+Page Up` / `Page Down` | El área de trabajo anterior / siguiente |
| `Super+Ctrl+Page Up` / `Page Down` | Llevar la ventana al área de trabajo anterior / siguiente |
| `Super+Shift+Left` / `Right` / `Up` / `Down` | Dar el foco al monitor en esa dirección |
| `Super+Shift+Ctrl+Left` / `Right` / `Up` / `Down` | Mover la ventana a ese monitor |
| `Alt+1` … `Alt+9` | Ir a la aplicación anclada en esa posición del dock |
| `Super+Tab` / `Alt+Tab` | Cambiar de aplicación / de ventana |

## Abrir aplicaciones

| Tecla | Acción |
| --- | --- |
| `Super+Space` | Buscar y abrir |
| `Super` | La vista de actividades: todas las ventanas abiertas, y la búsqueda |
| `Super+A` | Todas las aplicaciones instaladas |
| `Super+Return` | Terminal |
| `Ctrl+Alt+T` | Terminal, como la abren la mayoría de los escritorios Linux |
| `Super+Shift+B` | Navegador |
| `Super+Shift+F` | Archivos |
| `Super+E` | Carpeta personal |
| `Ctrl+Shift+Esc` | Mission Center, para ver y detener lo que está en ejecución |
| `Ctrl+Alt+Space` o `Super+.` | Selector de emojis |
| `Super+Ctrl+Shift+A` | Un agente de IA que conoce este sistema (`ame agent toggle` lo desactiva) |
| `Super+F1` | Este manual |

## Apariencia

| Tecla | Acción |
| --- | --- |
| `Super+Alt+Space` | El menú de Amethystora |
| `Super+Ctrl+Shift+Space` | Elegir un tema |
| `Super+Ctrl+Space` | Siguiente fondo de pantalla de este tema |
| `Super+Ctrl+D` | Cambiar entre el tema claro y el oscuro |

Lo mismo desde una terminal: `amethystora-theme list`, `amethystora-theme set <name>`,
`amethystora-theme bg next` o `ame desktop theme`.

## El escritorio

| Tecla | Acción |
| --- | --- |
| `Super+V` | Las notificaciones y el calendario |
| `Super+Shift+V` | El historial del portapapeles |
| `Super+L` | Bloquear la pantalla |
| `Super+D` | Mostrar el escritorio |
| `Print` | Hacer una captura de pantalla o grabar la pantalla |
| `Ctrl+Shift+Alt+R` | Iniciar o detener una grabación de la pantalla |
| `Super+Shift+Space` | Siguiente distribución de teclado, si tiene más de una |
