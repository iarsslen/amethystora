# Tastenkürzel

Amethystora ist für die Bedienung mit der Tastatur gebaut. `Super` ist die Taste mit dem Windows- oder
Command-Logo darauf. Dieselbe Liste zeigt `ame desktop keybindings` auf Englisch an, und das
Amethystora-Menü (`Super+Alt+Space`) erreicht das meiste von dem, was diese Tasten tun.

## Kacheln

PaperWM legt die Fenster einer Arbeitsfläche nebeneinander auf einen Streifen, der scrollt, damit das
fokussierte sichtbar bleibt. `Super` und eine Pfeiltaste wechselt zwischen Fenstern, mit `Ctrl` dazu
bewegt sich das Fenster selbst, mit `Shift` dazu geht es zu einem anderen Monitor.

| Taste | Aktion |
| --- | --- |
| `Super+Left` / `Right` / `Up` / `Down` | Das Fenster in dieser Richtung fokussieren |
| `Super+Ctrl+Left` / `Right` / `Up` / `Down` | Das Fenster in diese Richtung verschieben |
| `Super+Home` / `Super+End` | Das erste / letzte Fenster auf der Arbeitsfläche |
| `Super+[` / `Super+]` | Den Streifen verschieben, ohne den Fokus zu ändern |
| `Super+R` / `Super+Alt+R` | Die Breite schrittweise auf 38 %, 50 % und 62 % des Bildschirms setzen / zurück |
| `Super+Shift+R` | Die Höhe eines Fensters in einer Spalte schrittweise ändern |
| `Super+F` | Die Bildschirmbreite ausfüllen, und zurück |
| `Super+C` | Das Fenster zentrieren |
| `Super+I` | Das Fenster rechts in diese Spalte holen |
| `Super+O` / `Super+Shift+O` | Das unterste / dieses Fenster in eine eigene Spalte hinausschieben |
| `Super+T` | Das Fenster mitnehmen, solange `Super` gedrückt ist, und dort ablegen, wo Sie loslassen |
| `Super+Ctrl+Escape` | Das Fenster über dem Streifen schweben lassen oder zurücksetzen |
| `Super+Alt+Escape` | Die schwebenden Fenster aus- oder einblenden |
| `Super+Shift+C` | Wohin der Streifen ein fokussiertes Fenster scrollt: in Sicht, Mitte, Rand |
| `Super+Shift+W` | Wo sich neue Fenster öffnen: rechts, links, darunter |
| `Super+N` | Ein neues Fenster der App, in der Sie sich befinden |
| `Super+Ctrl+B` | Die obere Leiste auf dieser Arbeitsfläche aus- oder einblenden |
| `Super+Backspace` | Die Fenstergröße mit den Pfeiltasten ändern |
| `Super+W` | Das Fenster schließen |
| `Shift+F11` | Vollbild, mit Titelleiste |

## Arbeitsflächen

Sechs feste Arbeitsflächen, sodass eine Zahl immer dieselbe meint. Die, auf der Sie sich befinden, ist
links in der oberen Leiste hervorgehoben.

| Taste | Aktion |
| --- | --- |
| `Super+1` … `Super+6` | Zu dieser Arbeitsfläche wechseln |
| `Super+Shift+1` … `Super+Shift+6` | Das Fenster dorthin bringen |
| `Super+Page Up` / `Page Down` | Die vorherige / nächste Arbeitsfläche |
| `Super+Ctrl+Page Up` / `Page Down` | Das Fenster auf die vorherige / nächste Arbeitsfläche bringen |
| `Super+Shift+Left` / `Right` / `Up` / `Down` | Den Monitor in dieser Richtung fokussieren |
| `Super+Shift+Ctrl+Left` / `Right` / `Up` / `Down` | Das Fenster auf diesen Monitor verschieben |
| `Alt+1` … `Alt+9` | Zur angehefteten App an dieser Dock-Position wechseln |
| `Super+Tab` / `Alt+Tab` | Anwendung / Fenster wechseln |

## Starten

| Taste | Aktion |
| --- | --- |
| `Super+Space` | Suchen und starten |
| `Super` | Die Übersicht: alle offenen Fenster und die Suche |
| `Super+A` | Alle installierten Apps |
| `Super+Return` | Terminal |
| `Ctrl+Alt+T` | Terminal, so wie die meisten Linux-Desktops es öffnen |
| `Super+Shift+B` | Browser |
| `Super+Shift+F` | Dateien |
| `Super+E` | Persönlicher Ordner |
| `Ctrl+Shift+Esc` | Mission Center, um zu sehen und zu beenden, was läuft |
| `Ctrl+Alt+Space` oder `Super+.` | Emoji-Auswahl |
| `Super+Ctrl+Shift+A` | Ein KI-Agent, der dieses System kennt (`ame agent toggle` schaltet ihn aus) |
| `Super+F1` | Dieses Handbuch |

## Erscheinungsbild

| Taste | Aktion |
| --- | --- |
| `Super+Alt+Space` | Das Amethystora-Menü |
| `Super+Ctrl+Shift+Space` | Ein Thema wählen |
| `Super+Ctrl+Space` | Nächstes Hintergrundbild für dieses Thema |
| `Super+Ctrl+D` | Zwischen dem hellen und dem dunklen Thema wechseln |

Dasselbe in einem Terminal: `amethystora-theme list`, `amethystora-theme set <name>`,
`amethystora-theme bg next` oder `ame desktop theme`.

## Der Desktop

| Taste | Aktion |

| `Super+V` | Benachrichtigungen und der Kalender |
| `Super+Shift+V` | Der Verlauf der Zwischenablage |
| `Super+L` | Den Bildschirm sperren |
| `Super+D` | Den Desktop anzeigen |
| `Print` | Ein Bildschirmfoto oder eine Bildschirmaufnahme machen |
| `Ctrl+Shift+Alt+R` | Eine Bildschirmaufnahme starten oder beenden |
